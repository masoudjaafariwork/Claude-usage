Your Claude plan limits, always in view.

Claude Usage is a small always-on-top overlay that shows your current session, weekly and per-model limits — the same numbers as Claude’s Settings → Usage page — and keeps them fresh while you work.

At a glance

The numbers you would otherwise keep checking

Everything on Claude’s usage page, in one card that stays on top of your editor, browser or terminal — and refreshes itself.

  • Current session The 5-hour limit as a ring, with a live countdown to its reset.
  • Weekly limits All models, plus every model that has a weekly limit of its own.
  • This week, by app How your weekly usage splits between Claude Code, chats and Cowork.
  • Pace forecast “At this pace: limit in ~1h 15m” when your recent pace would hit 100 % before the reset.
  • Extra usage Your extra-usage spending, when you have it switched on.
  • Plan and account Your plan and the account the numbers belong to — hidden with one click while you share your screen.

Before you hit the wall

It tells you when to slow down

Colours change as a limit fills up, a notification arrives at 75 %, 90 % and 100 % — once per limit and usage window — and, if you like, another one when it resets. The tray icon’s ring always shows your fullest limit.

Features

Made to stay out of your way

A card when you want detail, a pill when you want space, and nothing in between you and your work.

  • Always on top, anywhere

    Drag it to any monitor and right up to the screen edge. It remembers where you left it; Move to display sends it to another screen.

  • Compact pill

    The session and your weekly limits as small rings in a slim bar. Choose which limits it shows.

  • Click-through lock

    Lock it and every click goes straight to the window underneath. Unlock from the tray or with a shortcut.

  • Your look

    Size 90–150 %, dark, light or like your system, and 50–100 % opacity — a see-through overlay turns solid while the mouse is over it.

  • Keyboard shortcuts

    Show or hide it with Ctrl+Alt+U and lock it with Ctrl+Alt+Shift+U — from any app (⌘⌥U on a Mac).

  • Tray ring

    The tray or menu-bar icon is a live ring of your fullest limit; its tooltip lists them all.

  • Several accounts

    Several Claude accounts? Give each one a window of its own and see them all at once, or switch in one window.

  • One-button sign-in

    Sign in lets your own Claude Code sign in through your browser. Not installed yet? Install Claude Code runs Anthropic’s installer.

  • Keeps the sign-in fresh

    When Claude Code’s sign-in expires after hours without use, the overlay lets Claude Code renew it in the background.

  • Fine when offline

    Offline, rate-limited or signed out: it keeps showing the last numbers, clearly marked as old, and catches up by itself.

  • Claude desktop app as backup

    No Claude Code sign-in? It can show the usage the Claude desktop app records by itself — no extra sign-in.

  • Updates itself

    New versions download in the background and install when you quit — or right away with Restart to update.

In every state

Clear about what it knows — and what it doesn’t

Expired sign-ins, a missing Claude Code, old data: the card always says what’s going on and offers the next step.

Privacy & security

Private by design

  • Read-only. It reads the sign-in Claude Code already keeps on your computer and never changes or refreshes it — refreshing would sign Claude Code out.
  • One destination. That token goes only to api.anthropic.com, in the same usage request Claude Code’s own /usage makes. The only other request is the update check on github.com.
  • No login of its own. No claude.ai password, cookies or session tokens — Anthropic doesn’t allow third-party apps to ask for them. Signing in is always your own Claude Code, in your own browser.
  • No telemetry. No analytics, no accounts, no servers of ours. The diagnostic log removes tokens and e-mail addresses before anything is written.
  • Open source. MIT-licensed; the code and the build workflow that makes the installers are on GitHub.

Getting started

Up and running in a minute

  1. Download and open it

    Pick the file for your system below. The builds aren’t code-signed yet, so the first start shows a warning — the steps are next to each download.

  2. Sign in — usually nothing to do

    Already use Claude Code? The numbers appear at once. Otherwise click Sign in (or Install Claude Code) on the card and finish in your browser.

  3. Put it where you want it

    Drag the card anywhere, switch to the compact pill, lock it so clicks pass through. Right-click or ⋯ opens the menu.

What you need

  • A Claude Pro, Max, Team or Enterprise plan — the plans with Claude Code.
  • Claude Code: the claude command, or the Claude Code extension for VS Code, Cursor, Windsurf or VSCodium. Not installed? The overlay installs it for you.
  • Or the Claude desktop app (Windows, macOS), running: rougher numbers, up to ~20 minutes old, without reset times.

FAQ

Questions, answered

Is this an official Anthropic app?

No. Claude Usage is an independent open-source project, not affiliated with or endorsed by Anthropic. It shows the same usage numbers Claude’s own apps show; the endpoint it reads them from isn’t a public API and can change without notice.

Which Claude plans does it work with?

Pro, Max, Team and Enterprise — the plans that include Claude Code. The free plan doesn’t include Claude Code.

Do I need Claude Code?

It’s the main source: the overlay reads the sign-in Claude Code keeps on your computer. The claude command and the Claude Code extension for VS Code (also in Cursor, Windsurf and VSCodium) both count. Not installed? The card’s Install Claude Code button runs Anthropic’s own installer and signs you in through your browser.

Without Claude Code, an open Claude desktop app can stand in: it records your usage about every 15 minutes, and the overlay shows that — up to ~20 minutes old, without reset times or the split by app.

Will it sign me out of Claude Code?

No. It never writes or refreshes Claude Code’s token — refresh tokens work only once, so refreshing would sign Claude Code out. When the sign-in expires after hours without use, the overlay starts your own Claude Code hidden with its built-in /usage command, and Claude Code renews its own sign-in. You can switch that off in the menu.

Does it send prompts or use up my limits?

It never sends a prompt to a model. It asks for your usage numbers every 3 minutes (1–10 minutes, your choice) — the same request Claude Code’s /usage makes — and backs off when the server asks it to. The background renewal runs Claude Code’s local /usage command, which is handled inside Claude Code and never reaches the model.

What leaves my computer?

Your Claude Code token, in the usage request to api.anthropic.com, and an update check on github.com every 6 hours, which sends nothing about you. Nothing else: no analytics, no crash reports, no servers of ours. This website doesn’t track you either — no cookies, no analytics, no third-party requests.

Why does Windows or macOS warn me when I open it?

The builds aren’t code-signed yet, so Windows SmartScreen and macOS Gatekeeper don’t know them. The steps to open it anyway are next to each download. The source code and the workflow that builds the installers are public.

Can I watch several Claude accounts?

Yes. Claude Code keeps each account in a config folder of its own (CLAUDE_CONFIG_DIR). Add those folders in the menu — or use Add account (sign in)…, which makes the folder and signs in for you — and give each account a window of its own. Each window checks only its own account.

How does it update?

It checks GitHub Releases shortly after it starts and then every 6 hours. The Windows installer and the Linux AppImage download a new version in the background and install it when you quit, or at once with Restart to update. The macOS app, the portable exe and the deb package tell you and open the download page.

How do I remove it?

Windows: Settings → Apps; your settings stay in %APPDATA%\Claude Usage until you delete that folder. macOS: move the app from Applications to the Trash. Linux: delete the AppImage, or sudo apt remove claude-usage.

Is it really free?

Yes — free and open source under the MIT licence. Issues and ideas are welcome on GitHub.
